# RETAIL-SALES-CUSTOMER-ANALYTICS-USING-SQL
Retail sales and customer analytics project using MySQL and SQL.

•	Analysed 20K+ orders and 5K customers to identify customer, product, and store-level performance drivers. 
•	Applied MySQL joins, CTEs, window functions, RFM segmentation, and profitability analysis to derive actionable business insights. 
•	Developed dashboard-ready analytical views for Power BI, enabling interactive performance analysis.
